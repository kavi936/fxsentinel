# 🎯 FXSentinel Investor Demo Guide

## 🚀 **Quick Demo Setup (5 minutes)**

### 1. Deploy Backend (Railway)
- Go to [railway.app](https://railway.app)
- Sign up with GitHub
- "New Project" → "Deploy from GitHub repo"
- Select your repo, set root directory to `backend`
- Copy the URL (e.g., `https://fxsentinel-backend.railway.app`)

### 2. Deploy Frontend (Vercel)
- Go to [vercel.com](https://vercel.com)
- Sign up with GitHub
- "New Project" → Import your repo
- Add environment variable: `VITE_API_URL=https://your-railway-url`
- Deploy

### 3. Demo URL
- **Frontend**: `https://your-app.vercel.app`
- **Backend API**: `https://your-app.railway.app/api/hello`
