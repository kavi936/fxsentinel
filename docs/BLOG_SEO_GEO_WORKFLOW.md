# Blog, SEO & GEO refresh workflow

> **Last updated:** 2026-06-03  
> **Refresh cadence:** Every **2–3 months**, publish **2–3** new or substantially updated posts (one topic cluster per cycle). Optional light touch monthly (sitemap `lastmod`, fix a broken link) if nothing new ships.

This doc is the single source of truth for how FXSentinel blog content is built, wired, and refreshed for search and generative-engine visibility (GEO).

---

## How blogs are built (architecture)

Blogs are **static React** — no CMS, no backend API.

| Layer | Location | Role |
|-------|----------|------|
| Article body | `src/components/blog-posts/<Name>.jsx` | `postData` + JSX `content` |
| Layout + SEO shell | `src/components/BlogPost.jsx` | Nav, `useMeta`, `BlogPosting` JSON-LD |
| Index cards | `src/components/Blog.jsx` | `blogPosts` array (metadata duplicated) |
| Routes | `src/App.jsx` | One `<Route>` per slug |
| Sitemap | `public/sitemap.xml` **and** `api/sitemap.js` | Must stay identical |
| Crawler metadata + HTML bodies | `src/data/blogCrawlerManifest.js` | Titles, excerpts, `crawlerHtml` for snapshots |
| Bot-visible HTML (build) | `public/crawler-snapshots/*.html` | Generated by `npm run generate:blog-html` |
| Bot routing | `middleware.ts` | Serves snapshots to bots on `/blog` URLs |
| Crawler summary | `index.html` | Hidden nav + article list (no JS required) |
| Internal links | `src/components/LandingPage.jsx` | Feature cards → “Read more” posts |

## Refresh cadence (recommended)

| Frequency | Action |
|-----------|--------|
| **Every 2–3 months** | Ship **2–3 posts** in one **topic cluster**; update sitemaps; bump `lastmod`; re-submit sitemap in Google Search Console if URLs changed. |
| **Same cycle** | Point at least one landing-page feature card at the newest relevant post. |
| **After deploy** | Spot-check [Rich Results Test](https://search.google.com/test/rich-results) on one new URL; query 1–2 LLMs (“What is FXSentinel?”) per `docs/2026_SEO_and _GEO to-do.md`. |
| **Avoid** | Weekly churn (diminishing SEO return); dates/years in titles that go stale without updates. |

### Topic clusters (rotate through)

1. **Trading economic news** — calendar, CPI/NFP, event prep  
2. **AI for forex** — news analysis, context vs signals  
3. **Macro & volatility** — central banks, sentiment, safe havens  

Cross-link new posts to 1–2 older posts in the same cluster.

## Checklist: add a new post

Copy this list each refresh cycle.

- [ ] **1. Slug** — kebab-case, keyword-rich, year only if content is time-bound (prefer evergreen slugs when possible).
- [ ] **2. Manifest** — add entry to `src/data/blogCrawlerManifest.js` (`crawlerHtml` = plain HTML for bot snapshots).
- [ ] **3. Component** — `src/components/blog-posts/<PascalCase>.jsx` wrapping `<BlogPost postData={...} />`.
- [ ] **4. Metadata** — `title`, `excerpt` (≈150–160 chars for meta), `date` (e.g. `June 3, 2026`), `readTime`, `category`, `author`.
- [ ] **5. Body** — `<h2>` / `<h3>`, lists, one `<blockquote>`; plain-language disclaimer where needed (not financial advice; not a broker).
- [ ] **6. Route** — import + `<Route path="/blog/<slug>" ...>` in `App.jsx`.
- [ ] **7. Index** — new entry at **top** of `blogCrawlerManifest.js` (Blog.jsx reads this automatically).
- [ ] **8. Crawler HTML** — run `npm run generate:blog-html` (also runs on `npm run build`); add link in `index.html` hidden nav.
- [ ] **9. Sitemap** — add `<url>` to `public/sitemap.xml` and `api/sitemap.js`; set `<lastmod>` to publish date (YYYY-MM-DD).
- [ ] **10. Internal links** — optional: update `LandingPage.jsx` feature “Read more”; cross-link in `crawlerHtml` and React body.
- [ ] **11. Deploy** — GSC sitemap re-submit; test bot snapshot: `curl -A "GPTBot" https://fxsentinel.io/blog/<slug>`

## Crawler-visible HTML (bots & LLMs)

Humans use the React SPA at `/blog/<slug>`. **Bots** (Googlebot, GPTBot, PerplexityBot, ClaudeBot, etc.) receive **static HTML** via `middleware.ts`:

1. `npm run build` generates `public/crawler-snapshots/<slug>.html` from `blogCrawlerManifest.js`.
2. Middleware maps `/blog` → `blog-index.html` and `/blog/<slug>` → `<slug>.html` for bot user-agents.
3. `index.html` includes a hidden `<nav>` with every blog URL plus a short article list (readable without JS).

Do **not** place static files under `public/blog/<slug>/` — Vercel would serve them to everyone and break the SPA.

Optional: `PRERENDER_TOKEN` still prerenders other routes; blog paths prefer snapshots first.

## SEO / GEO per post (automatic)

`BlogPost.jsx` already sets:

- Document title: `{title} | FXSentinel Blog`
- Meta description from `excerpt`
- `BlogPosting` schema: `headline`, `description`, `datePublished`, `author`, `url`, `articleSection`, `keywords`

No extra code unless you add custom `keywords` in schema (currently derived from category).
